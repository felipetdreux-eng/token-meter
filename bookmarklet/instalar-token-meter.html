Token Meter para o claude.ai

Um favorito que abre um painel com seus limites, o contexto da conversa e o selo de modelo certo/errado. Não instala nada.

Jeito 1: arrastar
  1. Mostre a barra de favoritos: Ctrl+Shift+B (no Mac, Cmd+Shift+B).
  2. Arraste este botão até a barra de favoritos:

Token Meter

Jeito 2: se arrastar não funcionar
  1. Clique em
  2. Clique com o botão direito na barra de favoritos e escolha Adicionar página…
  3. Em Nome, escreva Token Meter. Em URL, cole o código (Ctrl+V) e salve.
Usar
  1. Abra o claude.ai e clique no favorito Token Meter: o painel aparece no canto direito.
  2. Clique de novo para fechar. O botão – deixa o painel pequeno.
  3. Se recarregar a página (F5), clique no favorito outra vez.

Os limites vêm do próprio claude.ai; contexto e tokens são estimativas pelo texto da conversa. Tudo roda no seu navegador e só conversa com o claude.ai.
